# MoeKoe 本地音乐歌单管理

MoeKoe Music 插件：将本地音乐添加到「我喜欢」或自建歌单，在歌单详情中与在线歌曲一起显示，并加入播放队列。

[观看插件使用示例](./assets/demo.mp4)

## 安装

1. 下载仓库中的 [local-playlist-manager.zip](./local-playlist-manager.zip)。在 GitHub 上打开该文件后，使用下载按钮保存 ZIP。
2. 打开 MoeKoe Music 的插件管理，选择从 ZIP 安装插件。
3. 安装或更新后，刷新插件并刷新客户端页面；必要时重新启动客户端。

插件清单声明支持 MoeKoe Music 1.6.0 及以上版本，已针对 1.7.1 客户端调试。插件依赖客户端内部组件和扩展运行环境，其他版本的兼容性尚未逐一验证。

## 使用

先在「本地音乐」中选择并扫描音乐文件夹，再通过本地音乐的菜单选择要添加到的歌单。打开歌单后，本地歌曲应出现在歌曲列表中，可以与在线歌曲一起加入播放队列。

本地歌曲与歌单的关联只保存在当前客户端，音频文件不会上传到在线歌单，也不会自动同步到其他设备。移动或删除文件后可能需要重新扫描；重启后如果客户端请求文件访问权限，请按提示重新授权。

## 已知限制

- 歌单中包含本地歌曲时，批量操作暂不可用。
- 长歌单的随机播放和不同客户端版本的兼容性尚未完整验证。
- 该插件依赖客户端内部实现，客户端更新可能影响插件功能。

## 开发和打包

插件源码位于 [local-playlist-manager](./local-playlist-manager/)；ZIP 根目录必须包含 `local-playlist-manager/manifest.json`，才能通过客户端插件安装器识别。
